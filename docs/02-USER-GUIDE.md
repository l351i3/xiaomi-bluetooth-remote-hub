# 使用文档 —— 遥控器三端使用指南

> 适用：remote-hub 现网（T1 / macOS / Windows 三端，2026-10-14 版）
> 日常只需要记住四件事：**目标在哪个端**（网页台切，或**电源键连击**直接切）· **按住语音键说话**（松开上屏）· **长按 = 每个键的第二功能** · **电源键连击 = 切设备**

---

## 一、系统是什么

一只小米蓝牙遥控器（RC003），通过斐讯 T1（PHICOMM-T1）盒子中继，控制三个目标：

| 目标 | 你得到什么 |
|---|---|
| **ATV**（Apple TV 4K） | 遥控器直控电视（原厂手感 + 语音键默认一键开 YouTube，可改绑） |
| **macOS** | 遥控器 = 无线键盘+麦克风：语音输入、方向/回车/退格、跳输入框、点击焦点元素、切换/选择/关闭应用 |
| **Windows** | 同上（Windows 版），键位与 Mac **完全一致** |

目标三选一，随时切换（网页台或对 AI 说一句话）。

---

## 二、快速上手（3 分钟）

1. **确认遥控器目标**：打开 `http://T1_IP:8765/`，看当前高亮的目标，点按钮切换；
2. **按住语音键说话** → 松开 → 目标端输入法自动上屏（Mac=Chatterfly / Win=微信输入法）；
3. **按 OK=回车、返回=退格、方向键=方向键**——就是一套无线键盘；
4. **长按试试**：OK 长按=点击焦点元素；主页长按=应用选择器；电源长按=关闭当前应用（详见键位表）；
5. **不用开网页也能切设备**：**电源键连击**——1 击=ATV / 2 击=macOS / 3 击=Windows（立即切换，目标端有提示浮层）。

> ⚠️ 语音键是**纯长按**：必须「按住」再说（按一下即松开=不会触发）。

### 🖱 鼠标模式（长按直播键开启）

把遥控器变成一只**无线鼠标**——想点哪里就移到哪里，不用再靠 Tab 切焦点：

| 遥控器键 | 鼠标模式下的行为 |
|---|---|
| **方向键（按住）** | 光标滑行移动（轻点=精准微调，按住=加速滑行；斜向可同时按两个方向） |
| **OK** | 短按 = 左键单击；**长按 0.6s = 右键** |
| **音量 + / −（按住）** | 连续上滚 / 下滚 |
| **返回** | **退出鼠标模式**（回到普通键位） |
| **短按直播键** | 照常**跳输入框**（与普通模式行为一致） |
| **长按直播键** | 也可以关闭鼠标模式（开/关同一个键） |

**要点**：
- **开/关都有提示**：进入/退出时目标端弹出大字浮层「🖱 鼠标模式 / ⌨ 键盘模式」+ 提示音（Mac、Windows 都有）；
- **跳输入框兜底**（v2.8+；v1.6 精修）：对微信等无法自动定位输入框的应用，自动改为**点击窗口底部中央**
  （常规聊天/评论界面即输入框位置，等效把光标送进输入框）；v1.6 起会**先把目标窗口自动置前**（防被其它
  窗口遮挡）再点击，落点也更贴输入框文字行；
- 滑行是「按住才动」：松开立即停；即使遥控器信号断了（离开范围），1.2 秒内也会自动刹车；
- **电源 / 主页键在模式内照常工作**（与普通模式行为完全一致）：电源连击=切设备（1/2/3 击）、
  长按电源=关闭当前应用；短按主页=切换应用、长按主页=应用选择器——方便随时跳出去打开别的应用；
- 菜单键在模式内暂停工作，退出后恢复；
- 模式开着时切换网页台目标（如切到 ATV）不会自动退出，按**返回**即可退出（ATV 端无浮层提示）。

### ATV（Apple TV）

| 按键 | 行为 |
|---|---|
| 主页 | 短=回主屏 / 长=控制中心 |
| 返回 | 返回/菜单 |
| 方向 / OK | 方向 / 确认 |
| 音量 ± | 音量 |
| 电源 | 1 击=开关电视（切换）；**2 击=切到 Mac · 3 击=切到 Windows** |

| 菜单 | 播放 / 暂停 |

> 键位可随时改：见 §五 网页遥控台 → /keymap。

## 四、语音输入（重点功能）

**怎么用**：按住语音键（指示灯状态不限）→ 对着遥控器说话 → 松开 → 文字出现在目标端输入法里。

**原理**（一句话）：遥控器的麦克风音频经 T1 实时双播给 Mac 和 Windows → 各自注入虚拟声卡（Mac=BlackHole / Win=CABLE Input）→ 本机语音输入法听写上屏。**不做本地识别（非 Whisper），就用你已有的输入法。**

**要点**：
- 目标端必须装了语音输入法并选好虚拟麦克风（现网已配好，无需调整）；
- 小声说话也能识别（链路有 AGC 增益，已按实测调优）；
- 说话期间请**按住不放**；松开即提交，识别出文字。
- 若想对哪台上屏就切到哪个目标（音频恒双播，但注入行为按目标走）。

## 五、网页遥控台（`http://T1_IP:8765/`）

| 页面 | 功能 |
|---|---|
| 主页 | **三按钮目标切换**（ATV / Mac / Windows）+ **设备在线状态条**（三设备状态点，3s 自动刷新） |
| `/keymap` | 键位配置：三个 tab（atv / mac / win）× 全键位；每键可设「单击 / 长按 / 按住连发」 |

**设备状态点**（10-14 新增）：主页显示 ATV / macOS / Windows 三台设备的在线状态——
**绿=在线**（心跳正常）· **灰=离线**（关机/断网/服务未跑，附最后在线秒数）· **黄=未知**（心跳注册服务未运行，不影响其它功能）。设备离线期间，遥控器按键/语音会**暂停向它投递**（等它回来自动恢复，约 6 秒内判定）——不用再担心「发了没反应因为电脑不在」。

**改键位流程**：选 tab → 改下拉 → 保存（即时生效，**下一按键**即用新键位）→ 如需恢复，点「恢复默认」（回到 `keymap.default.json`）。

**注意事项**：
- 每次网页台**升级部署后**，需刷新页面一次（防旧页面把旧配置写回）；
- 保存有「配置指纹」保护：旧页面 + 新配置不匹配时会被拒绝（409），刷新即可。

## 六、高级动作速查（键位可选配）

在 /keymap 下拉里可选的完整动作清单（mac/win 通用）：

| 动作 | 含义 |
|---|---|
| `ENTER` / `ESC` / `TAB` / `SPACE` / `BACKSPACE` | 回车 / Esc / Tab / 空格 / 退格 |
| `UP` / `DOWN` / `LEFT` / `RIGHT` | 方向键 |
| `PAGEUP` / `PAGEDOWN` | 上一页 / 下一页 |
| `CLICK` | 点击「当前焦点元素」（浏览器按钮、链接等） |
| `FOCUS_INPUT` | 跳转到页面输入框（自动聚焦） |
| `APP:CYCLE` | 逐个轮询切换已打开的应用 |
| `APP:PICK` | 弹出应用选择器（图标网格） |
| `APP:TOGGLE` / `APP:NEXT` | 最近两应用互切 / 按名称序切换 |
| `APP:<应用名>` | 打开或切换到指定应用 |
| `APP:CLOSE` | 关闭当前前台应用 |
| `MOUSE:TOGGLE` | 开/关鼠标模式（一般配在直播键长按；切换动作本身也可绑任意键） |
| `TARGET:SWITCH` | ★ 电源（连击切设备）——绑到电源键单击即启用连击层：1 击=ATV / 2 击=Mac / 3 击=Win |
| `URL:<网址>` | 打开默认浏览器访问该网址 |
| `RUN:<命令>` | 执行一条命令（命令不含空格） |

> 动作清单以网页台实际下拉为准；新增动作随版本更新。

## 七、常见问题（FAQ）

| 现象 | 先查什么 |
|---|---|
| 按键没反应 | ① 网页台看**当前目标**对不对；② Mac 上跑 `python3 hs_health.py`（自动体检）；③ T1 `systemctl status t1-*` 看各服务（含 t1-presence 心跳） |
| 语音不上屏 | ① 是否**按住**说的；② 目标端输入法是否在读虚拟麦克风（BlackHole / CABLE Output）；③ T1 `t1-atvv` 服务是否 active |
| 长按没触发第二功能 | 长按需**满 0.6 秒**；某些键（返回/菜单/方向）的长按是「持续连发」语义 |
| 按电源键把电脑关了 | 那是**长按**=关闭当前应用（防误关）；**单击/连击**=切设备，不关任何东西 |
| 遥控器连不上 T1 | T1 蓝牙看护会自动重建（30s 巡检）；实在不行到 T1 跑 `systemctl restart t1bt-bluetooth` |
| ATV 没反应 | 网页台切到 ATV 目标；确认 `t1-relay` active |
| 网页台打开是旧样式/配置错乱 | **刷新页面**（防旧页面回写机制）；仍异常点「恢复默认」 |
| 快速切换目标 | ① **电源键连击**：1/2/3 击 = ATV / Mac / Win（不开电脑、不用网页也行）；② 网页台三按钮；③ 对 AI 说「把遥控器切到 Mac / Windows / ATV」 |
| 网页台设备状态点显示「离线」/「未知」 | 「离线」= 那台电脑关机/断网（按键会暂停投递、恢复自动续）；「未知」= 心跳服务未运行（其它功能不受影响，T1 上 `systemctl status t1-presence` 可查） |

## 八、维护速查

| 任务 | 怎么做 |
|---|---|
| 切目标 | 网页台三按钮 / 一句话 skill |
| 改键位 | `/keymap` 三 tab（保存后下一按键生效） |
| 恢复默认键位 | `/keymap` 页面底部「恢复默认」 |
| 看健康 | Mac：`python3 hs_health.py --fix --notify`；T1：`systemctl status t1-*`；Win：看计划任务与日志 |
| 升级 Windows | T1 起 8000 → Windows 跑 `update-win-receiver.ps1`（或双击 `.bat`） |
| 重启某端服务 | T1：`systemctl restart t1-voice-fwd` 等；Mac：`launchctl kickstart -k gui/501/com.remotehub.key-bridge`；Win：计划任务重启 |
| 完全静默（不用时） | 网页台把目标切到 ATV（Mac/Win 链路零打扰）即可 |
